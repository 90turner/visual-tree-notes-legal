Visual Tree Notes

Privacy Policy

Last updated: 2026-05-17

Visual Tree Notes is an offline-first notes application. This policy describes what data is processed and how it is handled.

Summary

  • We do not require account creation.
  • We do not sell user data.
  • We do not run ads.
  • Core notes data is stored locally on the user's device.
  • Internet is not required for core app functionality.

Data We Process

User content: notes and tree data

  • Trees, nodes, and notes entered by the user.
  • Stored locally on-device in app-managed local storage.

Purchase state

  • Premium entitlement state related to the one-time unlock.
  • Stored locally to enable or disable premium features.
  • The purchase flow itself is handled by platform stores.

Diagnostics

  • No dedicated remote telemetry or analytics pipeline is required for core usage.
  • Local logs may appear during development builds.

Data Sharing

We do not share notes content with third parties as part of normal offline use.

Platform stores, including Microsoft, Apple, Google, and Amazon, may process transaction data when users make purchases, according to their own policies.

Security

  • Data remains local by default.
  • Users are responsible for device security and backups.
  • Exported files are user-controlled and stored where the user saves them.

User Control

Users can:

  • Create, edit, and delete local data in-app.
  • Export data using available export features.
  • Remove app data by uninstalling the app and/or deleting app storage.

Children

Visual Tree Notes is not directed to children under 13.
