# Visual Tree Notes Legal Pages

This folder is ready for GitHub Pages.

Recommended free publishing setup:

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Set source to `Deploy from a branch`.
5. Select branch `main` and folder `/docs`.

Expected GitHub Pages URLs after publishing:

- `https://90turner.github.io/notes_app/`
- `https://90turner.github.io/notes_app/privacy/`
- `https://90turner.github.io/notes_app/terms/`

When `visualtreenotes.app` is ready, either point the custom domain at this Pages site or replace these temporary URLs in release metadata.
